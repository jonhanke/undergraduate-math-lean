# UndergradKB.LinearAlgebra

Proofs of the linear-algebra results of Axler (4th ed.) and Hefferon (4th ed.) that Mathlib lacks, and (in `Course/`)
book-named wrappers of the results Mathlib has. Every headline is tagged `@[kb "<book key>" "<item>, p. <pdf page>"]`.
Coverage: docs/coverage/linear-algebra/.
