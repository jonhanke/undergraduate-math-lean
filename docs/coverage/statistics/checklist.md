# Statistics checklist (master)

One row per mathematical result of the first college course in statistics (descriptive statistics, probability
rules, discrete and continuous distributions, the central limit theorem, confidence intervals, hypothesis
tests, regression). Statements are one-line paraphrases in our own words; item references are `§section @p<pdf
page>` for the book's unnumbered boxed statements and `Example n.m @p<pdf page>` for numbered examples that a
result uses (pdf page = page index of the text in the refs). Procedures (a test, an interval) are rows for the
theorem that justifies them (the distribution of the statistic); recipes and data examples are 'not a result'.
Book maps are generated from this file by `scripts/coverage/book_maps.py` (never edit them by hand); this file
is generated by `docs/coverage/statistics/parts/build.py`. Names in `where` are checked mechanically against
the Mathlib sources by `scripts/coverage/check_statistics.py --names`.
