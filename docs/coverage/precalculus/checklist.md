# Precalculus: master checklist

One row per mathematical result of C. Stitz, J. Zeager, *Precalculus* (2013); statements are our own one-line paraphrases. Items are the book's numbers with the pdf page (`p.N`); `§s.t` marks an unnumbered boxed result. Classifications: in Mathlib; partly in Mathlib; proved here (proved in this repository, usually the Trigonometry topic); not formalized; not a result. Book maps are generated from this file by `scripts/coverage/book_maps.py`. Overlap with the Trigonometry topic (chapters 10-11) is noted in the `note` column and not duplicated in Lean.
