# Combinatorics checklist (master)

One row per mathematical result. Statements are one-line paraphrases in our own words; item references are
`label @p<pdf page>` (pdf page = page index + 1 of the text in the refs). Book maps are generated from this
file by `scripts/coverage/book_maps.py` (never edit them by hand). Classification vocabulary: in Mathlib;
partly in Mathlib; not formalized; not a result. Names in `where` are checked mechanically against the Mathlib
sources by `scripts/coverage/check_combinatorics.py`.
